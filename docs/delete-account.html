뜨개동네 계정 삭제 안내

개발사: 펌테크주식회사 · 앱: 뜨개동네

앱에서 직접 삭제 (즉시)

  1. 앱을 열고 하단 마이(사람 아이콘) 탭으로 이동
  2. 오른쪽 위 설정(톱니) → 계정 삭제
  3. 안내를 읽고 "삭제"를 입력하면 즉시 삭제됩니다

이메일로 요청

앱을 사용할 수 없는 경우 가입한 이메일 주소로 knitup.official@gmail.com 에 "계정 삭제 요청"이라고 보내 주세요. 본인 확인 후 3영업일 안에 삭제하고 회신합니다.

삭제되는 데이터

  • 계정(이메일, 이름, 프로필 사진), 프로필(닉네임, 동네, 위치, 단계, 소개)
  • 게시글, 답글, 좋아요, 작품 인증, 후기, 업로드한 사진
  • 친구 관계, 채팅 메시지, 모임 참여 기록, 내가 만든 모임

삭제 후 복구할 수 없습니다. 신고 기록은 분쟁 대응을 위해 최대 1년간 보관될 수 있습니다.
