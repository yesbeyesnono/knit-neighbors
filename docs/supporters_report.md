# 1기 서포터즈 — 최종 보고 (2026-09-26)

지시서 `knitup/docs/supporters_spec.md`대로 만들었습니다. 대표님 결정(운영 DB에 추가만 적용 · 작품 인증은 올리면 바로 10점)에 따라 진행했습니다.

## 1. 완료된 것
- 점수 규칙 7가지가 전부 서버(DB)에서 계산됩니다. 출석 1 · 작품 인증 10 · 글 3 · 댓글 1(하루 2개, 내 글 댓글 제외) · 설문 10(회차당 1번) · 버그 채택 10 · 친구 초대 20. 하루 한도는 한국시간 기준.
- 글·댓글·작품을 지우면 같은 점수가 빠집니다. 같은 근거로 두 번 적립되지 않습니다.
- 60일(30일씩 2구간) 판정, 구간마다 100점 조건, 등급(기본/우수/MVP/미달) 자동 확정, "1기 서포터" 뱃지, MVP 5명은 1기 전원 종료 후 확정. 매일 00:10에 자동 실행.
- 정원 100명, 가득 차면 자동 마감. 동시에 신청해도 100명을 넘지 않게 잠금 처리.
- 친구 초대: 초대 링크(`…/?ref=코드`)·추천인 닉네임 칸, 프로필 완성 + 다음 날 재접속 때 20점. 자기 추천·기존 계정·추천인 변경은 차단.
- 앱 화면: 상단 "베타 운영 중 · 1기 서포터 모집 중 · 잔여 N명" 띠, 안내 카드([시작하기]/[다음에]), 서포터 화면(구간 진행 바·D-day·오늘 한도·최근 적립·친구 초대·버그 제보·설문·서포터 채팅방), 첫 활동 뒤 초대 팝업 1회, 프로필 뱃지, 응원 알림(30·60·90점, 구간 D-7 각 1회).
- 지기 AI: "서포터즈 할래요"라고 하면 안내 카드를 띄웁니다(등록은 카드 버튼이 처리).
- 텔레그램: 버그 제보가 오면 [채택(+10점)]/[반려] 버튼. 아침 브리핑에 서포터 요약(신규·잔여 정원·오늘 적립·미처리 제보·어제 종료자 등급)이 붙습니다.
- 관리자 콘솔 › 1기 서포터즈: 현황, 모집 마감/정원, 버그 제보 채택, 설문 만들기(4회차), 응답 CSV, 서포터 명단(구간별 점수·등급·초대 코드).

## 2. 체크리스트 결과 — 17항목 중 16 통과, 1 부분 통과
`supabase/tests/supporters_test.sql` 5개 블록을 운영 DB에서 롤백 모드로 돌렸습니다.
- 통과: 정원 초과 FULL·마감 / 중복 신청 1건 / 출석 1점 / 글 3점·댓글 2점 / 내 글 댓글 0 / 작품 하루 10점 / 삭제 차감 / 설문 회차당 1번 / 버그 채택 10·반려 0 / 초대(같은 날 0, 다음 날 +20, 자기 추천·기존 계정·변경 차단) / 구간 경계(29일차=1구간, 30일차=2구간) / 60일 이후 0 / 등급 none·basic·excellent→MVP / 응원 알림 1회 / 비서포터 0점 / RLS(남의 점수 조회 0건, 직접 insert 거부) / 앱·콘솔 문법 검사 통과
- 부분 통과: "동시 신청 2건에서 100명을 넘지 않음"은 DB 잠금(`for update`)으로 막았지만, 실제로 두 요청을 동시에 쏘는 테스트는 만들지 못했습니다(한 세션에서는 동시 실행이 안 됨).
- 지시서와 다른 점: 작품 인증은 "AI 승인 시점"이 아니라 "올린 시점"에 10점(대표 결정). 알림은 푸시가 없어 앱 안 알림(🔔 활동)으로 보냅니다.

## 3. 대표가 직접 해야 할 일
1. **푸시**: "올려줘" 하시면 앱·콘솔 화면이 반영됩니다(DB·서버 함수는 이미 적용됨 → 지금도 신청·적립은 동작).
2. **설문 문항 입력**: 콘솔 › 1기 서포터즈 › 설문 추가에서 1~4회차를 만들어 두세요(기간 안에만 답할 수 있음). 한 줄에 질문 하나, 객관식은 「질문 | 보기1 / 보기2」.
3. **실물 보상 발송**: 매일 아침 브리핑의 "어제 종료: 닉네임 등급" 또는 콘솔 명단에서 기본 이상인 분께 매거진·쿠션·실 키트를 보내세요. 배송지는 이벤트 기능과 달리 자동 수집하지 않으니 채팅으로 받으셔야 합니다.
4. **모집 시작/마감**: 콘솔에서 정원·마감을 바꿀 수 있습니다. 지금은 열려 있습니다(정원 100).
5. **서포터 채팅방**: 첫 서포터가 [서포터 채팅방]을 누르면 지기 계정 소유의 단체방 "1기 서포터즈"가 자동으로 생깁니다. 대표님도 지기 계정으로 들어가 인사해 주세요.

## 4. 확인 방법
- 앱: 로그인 → 상단 연두 띠 "베타 운영 중 · 1기 서포터 모집 중" 누르기 → 안내 카드 → [시작하기] → 서포터 화면. 마이 › 설정 › 1기 서포터즈로도 들어갑니다.
- 지기 채팅에 "서포터즈 할래요"라고 쓰면 카드가 옵니다.
- 서포터 화면 › [버그 제보] → 텔레그램에 [채택]/[반려] 카드가 옵니다.
- 콘솔 › 1기 서포터즈에서 명단·점수·제보·설문을 봅니다.
- 테스트 계정: demo1~6@knit.local (비번 knit1234). 테스트 흔적은 남기지 않았습니다.
