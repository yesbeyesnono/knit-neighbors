# knitup(뜨개동네) 운영 안내서 — 비상시·인수인계용

Claude 를 쓸 수 없게 되었을 때, 대표나 다른 개발자·다른 AI 가 이 문서 하나로 앱을 계속 운영하고 고칠 수 있도록 쓴 글이다(2026-11-16).
비밀 값은 여기에 없다. 어떤 열쇠가 어디에 있는지는 `열쇠목록.md` 를 본다.

| 웹 앱·관리자 콘솔 | GitHub Pages: https://yesbeyesnono.github.io/knit-neighbors/ · `…/admin.html` | 계속 돌아감 |

## 2. 매일의 운영 (콘솔만으로 가능)

콘솔: https://yesbeyesnono.github.io/knit-neighbors/admin.html (관리자 구글 계정으로 로그인)
- **오늘**: 처리할 신고·검토할 글·기다리는 신청(가게·작가). 버튼으로 숨김/무시/승인
- **지기 문의함**: 회원이 '지기에게 말하기'로 보낸 대화에 답장
- **회원**: 검색 → 정지·동네 바꾸기·안내 보내기 · **글·인증 / 모임**: 숨기기·삭제
- **알리기**: 전체 공지·알림, 첫 화면 공지 카드, 앱 안 '공지·새 소식', 이벤트
- **가게·작가·도안 › 초대·안내**: 초대 링크 만들기, 작가 지정
- 텔레그램: 긴급 건은 봇이 바로 알려 주고 버튼으로 처리할 수 있다

## 3. 급할 때

| 상황 | 할 일 |
|---|---|
| 나쁜 글·사기 글 | 콘솔 › 오늘 또는 글·인증에서 [숨김]. 회원은 회원 화면에서 [정지] |
| 앱이 안 열림 | https://status.supabase.com 과 https://www.githubstatus.com 확인. 우리 쪽 문제가 아니면 기다린다 |
| 방금 올린 수정 때문에 고장 | 아래 4-1 의 '되돌리기'. 웹은 몇 분 안에 원래대로. 스토어 앱은 심사를 거쳐야 하므로 서버 스위치로 먼저 끈다 |
| 옛 버전 앱을 막아야 함 | Supabase › Table Editor › `app_config` › `min_version` 값을 올린다 |
| 첫 화면 공지·이벤트·채팅 배경을 끄려면 | `app_config` 의 `home_notice` / `ddeuchin_event` / `chat_theme` 의 `active` 를 false 로 |
| AI 가 이상하게 굶 | Supabase › Edge Functions › Secrets 에서 `ANTHROPIC_API_KEY` 를 지우면 AI 판단만 꺼진다(규칙 감지·버튼 처리는 계속). 다른 회사 모델로 바꾸려면 `AI_PROVIDER=openrouter` + `OPENROUTER_API_KEY` |
| 푸시가 안 감 | Supabase › Edge Functions › `push-send` 로그. 애플 키(`APNS_KEY`)·구글 키(`FCM_SERVICE_ACCOUNT`)가 만료·삭제됐는지 |
| 안드로이드 새 버전이 고장 | Play Console › 프로덕션 › 출시 중단. 이전 버전으로 되돌릴 수는 없으니 고친 빌드를 번호를 올려 다시 올린다 |
| 데이터를 잘못 지움 | Supabase › Database › Backups 에서 복구(매일 자동 백업, 최근 7일). 복구는 그 시점 뒤의 모든 변경을 되돌리므로 신중히 |

## 4. 앱을 고치는 법

### 4-1. 화면(회원 앱·콘솔)
1. `docs/index.html`(앱) 또는 `docs/admin.html`(콘솔)을 고친다. 프레임워크 없이 HTML·CSS·JS 가 한 파일에 있다
2. 커밋하고 main 에 푸시한다
3. 몇 분 뒤 웹(https://yesbeyesnono.github.io/knit-neighbors/)에 반영된다. 동시에 Codemagic 이 아이폰 빌드를 만들어 TestFlight 에 올린다(커밋 메시지에 `[skip ci]` 를 넣으면 둘 다 건너뛰므로, 그때는 GitHub › Settings › Pages 에서 다시 배포)
4. 스토어에 내보내려면: 버전 번호 세 곳을 올리고(`docs/index.html` 의 `APP_VERSION`, `ios/App/App.xcodeproj/project.pbxproj` 의 `MARKETING_VERSION`, `android/app/build.gradle` 의 `versionName`·`versionCode`) → App Store Connect 에서 새 버전을 만들어 TestFlight 빌드를 고르고 심사 제출 → 안드로이드는 4-2
- **되돌리기**: `git revert <커밋>` 후 푸시. 또는 GitHub 웹에서 그 커밋의 Revert
- 고치기 전에 읽을 것: 저장소 맨 위 `CLAUDE.md`(지켜야 할 규칙), 자세한 경위는 `resources/handover/작업기록_전체.md` 에서 낱말로 검색
- 점검 도구: `python tools/audit/audit.py`(안 쓰는 함수·없는 함수 호출), `tools/audit/regress.mjs`(주요 화면 20장 찍기)

### 4-2. 안드로이드 빌드 (대표 PC)
필요한 것: JDK 21, Android SDK(`C:/Android/Sdk`), Node, 그리고 **열쇠 파일 3개**(`열쇠목록.md` 의 '이 PC 에만 있는 파일')
```
npm ci
npx cap sync android
cd android
./gradlew bundleRelease --no-daemon
```
결과: `android/app/build/outputs/bundle/release/app-release.aab` → Play Console › 프로덕션 › 새 버전 만들기 › 업로드 › 검토 전송. 올릴 때마다 `versionCode` 를 1 올린다.

### 4-3. 서버
- 구조(표·함수·권한·예약 작업)의 사본: `supabase/snapshot/`(읽기용). 날짜순 설명: `supabase_schema.sql`. 실제 원본은 Supabase 안의 마이그레이션 기록
- 고칠 때: Supabase › SQL Editor 에서 실행. **공개된 앱이 쓰는 중이므로 추가만 하고, 있던 칼럼·함수는 지우지 않는다.** 새 표는 권한(grant)을 꼭 적는다(`CLAUDE.md` 4절)
- 서버 함수(Edge Function) 10개의 원본: `supabase/functions/<이름>/index.ts`. 배포: Supabase CLI `supabase functions deploy <이름> --project-ref thfcrodfaitzrzlrxyir`(jigi·push-send 등은 `--no-verify-jwt`), 또는 Supabase 화면에서 붙여 넣기
- 권한 시험: `supabase/tests/permissions_test.sql` 을 SQL Editor 에서 실행(결과가 오류 메시지로 나오고 모두 되돌려짐)
- 구조 사본 새로 만들기: `tools/backup/snapshot.sql` 을 실행한 결과를 파일로 저장 → `python tools/backup/make_snapshot.py <파일>`

### 4-4. 홈페이지
`yesbeyesnono/knitup-home` 저장소의 파일을 고쳐 푸시하면 https://app.knitup.co.kr 에 반영된다. 약관·개인정보처리방침 등 5개 문서는 이 저장소(`knit-neighbors`)의 `docs/` 가 원본이고, 홈페이지 저장소의 `sync-legal` 작업이 매일 새벽에 가져간다(바로 반영하려면 Actions 에서 수동 실행).

## 6. 다른 사람·다른 AI 에게 넘길 때
1. GitHub 저장소 2개(`knit-neighbors`, `knitup-home`)에 초대한다(쓰기 권한)
2. Supabase 프로젝트에 구성원으로 초대한다
3. 이 문서와 `CLAUDE.md` 를 먼저 읽게 한다. 규칙(공개 뒤에는 추가만, 시안 먼저, 비밀 값은 적지 않기)을 지키게 한다
4. 스토어(App Store Connect·Play Console)·Codemagic 은 필요할 때만 권한을 준다
5. 열쇠 값은 메신저·메일로 보내지 말고 비밀번호 관리 앱의 공유 기능으로 전한다

## 7. 계정이 막히는 일에 대비
- 구글·애플·Supabase·GitHub·Codemagic 계정에 2단계 인증과 복구 전화번호를 걸어 둔다
- 각 서비스에 **두 번째 관리자**(믿을 수 있는 사람의 계정)를 추가해 둔다. 예전에 법인 구글 계정이 본인인증에 막혀 로그인 설정을 통째로 새로 만든 일이 있었다
