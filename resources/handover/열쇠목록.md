# 열쇠 목록 — 무엇이 어디에 있나 (값은 적지 않는다)

이 저장소는 공개이므로 **값은 절대 적지 않는다.** 이 표는 "무엇을 잃어버리면 무슨 일이 생기는지"와 "어디서 다시 받는지"만 적는다(2026-11-16).
표시: ★ = 잃으면 복구가 어렵거나 오래 걸림 → 꼭 따로 보관.

## 1. 대표 PC 에만 있는 파일 (저장소에 올라가지 않음) — 가장 급함

| 파일 | 쓰임 | 잃으면 | 다시 받는 곳 |
|---|---|---|---|
| ★ `android/keys/upload-keystore.jks` + `android/keystore.properties`(비밀번호) | 안드로이드 앱 서명(업로드 키) | 안드로이드 업데이트를 못 올림 | Play Console › 앱 무결성 › 업로드 키 재설정 요청(구글 심사, 며칠 걸림) |
| `android/app/google-services.json` | 안드로이드 푸시(Firebase) | 빌드가 안 됨 | Firebase 콘솔 › 프로젝트 `knit-neighbors` › 앱 설정에서 다시 내려받기 |
| `*.p8`(Apple 키: 로그인용·푸시용) — **2026-11-16 에 이 저장소 폴더 안에서는 찾지 못함. 대표가 다른 곳에 보관 중인지 확인 필요** | Apple 로그인 시크릿 재발급(`tools/apple-secret.js`), 푸시 | 로그인 시크릿을 새로 못 만듦(만료 2027-03-13) | Apple Developer › Keys 에서 새 키 발급(.p8 은 한 번만 내려받을 수 있음) |
| `.claude/launch.json` | 스테이징 서버 설정 | 다시 만들면 됨 | — |

**보관 방법**: 위 파일들을 USB 한 개와 비밀번호 관리 앱(또는 암호를 건 압축 파일)에 따로 둔다. OneDrive 안에만 두지 않는다.

## 2. Supabase 안의 비밀 값 (Edge Functions › Secrets)

| 이름 | 쓰임 | 없으면 |
|---|---|---|
| `ANTHROPIC_API_KEY` (또는 `OPENROUTER_API_KEY` + `AI_PROVIDER`, `AI_MODEL_FAST`, `AI_MODEL_SMART`) | 지기 AI, 볼밴드 읽기, 사진 판별 | AI 기능만 꺼짐 |
| `TG_BOT_TOKEN`, `TG_WEBHOOK_SECRET`, `TG_ADMIN_CHAT_ID` | 텔레그램 운영 알림 | 텔레그램 알림·버튼 처리가 멈춤 |
| `APNS_KEY`, `APNS_KEY_ID`, `APNS_TEAM_ID` | 아이폰 푸시 | 아이폰 푸시가 안 감 |
| `FCM_SERVICE_ACCOUNT` | 안드로이드 푸시 | 안드로이드 푸시가 안 감 |
| `JUSO_KEY` | 도로명주소 검색(동네 찾기·동네 자동 보정) | 동 이름 검색만 됨 |
| DB `jigi_config.hook_secret` | DB → 서버 함수 호출 확인 | 자동 검사·알림 호출이 거절됨 |

값을 잊어도 각 발급처에서 새로 받아 넣으면 된다(★ 아님).

## 2-1. 백업 저장소(`yesbeyesnono/knitup-backup`)의 비밀 값 (GitHub › Settings › Secrets)

| 이름 | 쓰임 | 없으면 |
|---|---|---|
| `SUPABASE_DB_URL` | 매일 백업이 데이터베이스에 접속하는 주소(비밀번호 포함) | 백업이 실패함(메일로 알림). 데이터베이스 비밀번호를 바꾸면 여기도 고칠 것 |
| ★ `BACKUP_PASSPHRASE` | 백업 파일을 잠그는 암호 | **잃으면 그동안의 백업을 열 수 없다** — 비밀번호 관리 앱에 따로 보관 |
