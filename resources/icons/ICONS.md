# 뜨개동네 아이콘 스펙 (Claude Design 제작용)

앱의 이모지를 전부 이미지 아이콘으로 교체하기 위한 목록입니다.
**파일명 = 키** 로 `docs/icons/<key>.svg` 에 넣으면 앱이 그대로 매칭합니다 (코드 수정 없이 `ICON_IMAGES=true` 스위치만 켬).

## 공통 스타일 가이드
- 톤: Threads 계열 흑백 UI. **단색 검정(#000) 라인 아이콘**, 선 굵기 1.8~2px, 모서리 둥글게, 여백 균일.
- 포맷: **SVG, 24×24 viewBox, 배경 투명**, `currentColor` 사용(색 지정 없음). PNG가 필요하면 @2x·@3x (48/72px).
- 예외(색 허용): `cert`(작품 인증 — 금색 포인트 가능), `wave`(손 — 살구/노랑 포인트 가능). 나머지는 단색.
- 표시 크기: 본문 안 1.15em(약 16~18px), 지도 핀 손 배지 13px, 안내 슬라이드 48px. 작은 크기에서도 형태가 살아야 함(디테일 최소화).

## 이미 SVG인 아이콘 (같은 세트로 다시 그려도 됨)
하단 내비 `home`(커뮤니티) · `map`(지도 핀) · `plus`(새 글) · `send`(채팅, 종이비행기) · `person`(마이),
글 카드 `heart`(좋아요) · `reply`(말풍선) · `share`(공유),
상단 `bell`(활동) · `gear`(설정) · `photo`(사진 첨부) · `back`(‹ 뒤로).
→ 다시 그리면 `docs/icons/nav-home.svg` 처럼 `nav-` 접두어로 전달해 주세요.

## 이미지로 바꾸지 않는 것 (텍스트 안 이모지)
토스트 문구, 자동 입력 인사말("…🧶 같이 떠요!"), 앱 이름 등 순수 텍스트 속 이모지는 문장의 일부라 그대로 두거나 문구를 바꿉니다.

## 납품 후 적용 절차
1. `docs/icons/` 에 20개 SVG 저장(파일명 = 키).
2. `docs/index.html` 의 `const ICON_IMAGES = false` → `true`.
3. 푸시 → 웹 즉시 반영, iOS는 TestFlight 빌드, Android는 .aab 재빌드.
