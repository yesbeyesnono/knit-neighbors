# 보류 중인 작업 — 뜨개동네 수정 작업 지시 (2026-11-13 대표 전달, 같은 날 "잠시 보류")

대표가 "큰 작업이 될 수 있다"며 보류함. **대표가 "내가 어떤 일을 해야 하지?" / "남은 일이 뭐지?"라고 물으면 이 문서를 다시 보여 줄 것.**
아직 아무것도 만들지 않았다(서버·앱 변경 없음).

## 대표가 준 지시 원문

### 1. 위치 흐림 격자 200m → 100m
- set_fuzzy_location: 격자 0.0018° → 0.0009° (경도 쪽도 같은 비율). 정확 좌표는 저장하지 않는 원칙 유지
- 기존 회원은 다음 위치 갱신 때부터 새 격자 적용 (원래 좌표가 없으므로 일괄 재계산하지 않음)
- docs/ 안의 '200m' 표기(privacy·terms·support·index·admin)와 app.knitup.co.kr 소개 페이지를 모두 '약 100m'로 수정
- 같은 좌표 분산(fetchPins의 spread 26px)은 그대로 유지

### 2. 지도 핀 노출 우선순위
nearby_profiles 정렬을 '거리순'에서 '아래 순위 → 같은 순위 안에서 거리순'으로 변경
(반환 모양 유지, 반경 5km·200명·반경 밖 작가 300명 규칙 유지)
1) 작가 (is_author)
2) 손 든 회원 (waving)
3) 신규 가입자 (onboarded_at 14일 이내)
4) 활동 많은 회원 (최근 30일 글·댓글·작품 인증·모임 참여 합 상위 — 기준값은 제안해 줄 것)
5) 최근 접속자 (7일 이내)
6) 나머지
7) 장기 미접속자 (30일 이상, 맨 뒤)
- 200명이 넘으면 이 순서대로 200명을 채움
- 앱 fetchPins: 마커를 순위가 낮은 것부터 그려서 높은 순위 핀이 위에 오게 함. 작가 핀 z-index는 유지
- 마지막 접속 시각 칼럼이 없으면 profiles에 추가하고 check_in에서 갱신

### 3. 작품 인증 가이드라인
- 인증 화면 위쪽에 안내 한 줄: "완성작만 인증해요 · 전체가 보이는 사진 1장 필수 · 남의 도안이면 도안과 작가를 적어 주세요"
- 도안 출처 칸 추가: [자작] / [다른 도안: 도안 이름 + 작가] → works에 칼럼 추가 (null 허용, 옛 앱은 그대로 동작)

### 4. AI 사진 확인 (지기)
- 인증 사진을 올리면 AI가 사진을 보고 기법을 추천하고, 체크는 회원이 직접 함 (read-band·ddeuchin-check와 같은 Edge Function 방식)
- 등록 후 AI 확인: ① 뜨는 중으로 보임(바늘이 꽂혀 있음 등) ② 체크한 기법과 사진이 크게 어긋남 ③ 전체 사진 없음
  → 텔레그램 지기로 관리자에게 알림. 자동 삭제는 금지하고, 회원에게는 "글로 옮길까요?" 정도로 부드럽게 안내
- 상급(level≥4) 기법이 들어간 인증은 AI 확인을 통과하기 전까지 작가 자격(author_adv_count) 계산에서 제외
- 원칙: AI는 판정하지 않고 제안과 경고만 함

### 공통
- 마이그레이션 이름과 supabase_schema.sql 주석은 기존 규칙대로 작성
- 끝나면 변경 요약과 대표가 직접 해야 할 일(스토어 재심사 필요 여부 등)을 알려 줄 것
