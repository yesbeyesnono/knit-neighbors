## 1. 개인정보 보호책임자·취급자
- 보호책임자: [대표] 성명·직위 (대표이사) — 방침 13항과 동일
- 취급자: 관리자 3인(콘솔 `admins`: knitup.official, yesbeyesnono, cocos.jay) ✅

- 퇴직·역할 변경 시 당일 권한 회수 [대표 운영 규칙]

## 2. 접근 권한 관리
- 앱: RLS + GRANT, 서버 계산값은 클라이언트 수정 불가 ✅ (`permissions_test.sql` 4블록, 마이그레이션마다 실행 ✅)
- 콘솔: `is_admin()` 검사, 모든 조치 admin_logs ✅
- 대시보드·GitHub·Codemagic·Apple·Google: 대표 계정 1인, **2단계 인증** ⏳[대표]
- 비밀번호 로그인은 테스트 계정만(demo1~6), 출시 전 삭제 ⏳

## 3. 접근 통제·인증
- 서비스 키·봇 토큰·AI 키는 Supabase Secrets 에만, 파일·채팅 기재 금지 ✅
- 텔레그램 봇 웹훅 주소 매시 확인·복구(jigi-guard) ✅
- Supabase Auth 유출 비밀번호 차단 켜기 ⏳[대표]

## 4. 접속 기록 보관·점검
- 1급 데이터(이메일·배송지) 열람: `access_logs` 400일 보관 ✅ · 관리자 행위: admin_logs 영구 ✅
- Supabase 플랫폼 로그 7일 — 사고 의심 시 즉시 내보내 보관 [대표 운영 규칙]
- 월 1회 점검: access_logs 이상 여부, admins 목록, Secrets 목록, 협업자 목록 [대표]

## 5. 암호화
- 전송 구간 HTTPS ✅ · 저장: Supabase(AWS) 디스크 암호화 ✅ · 비밀번호는 Supabase Auth 해시 ✅
- 고유식별정보·계좌·카드 정보 미수집 ✅ (결제 도입 시 PG 위탁, 앱 미보관)

## 6. 악성 프로그램·보안 프로그램
- 서버리스(Supabase)라 OS 관리 없음. 클라이언트 의존성은 npm ci 고정, 빌드는 Codemagic ✅

## 7. 물리적 안전조치
- 서버: AWS 서울 리전(Supabase 관리) ✅ · 종이 문서 없음 ✅ · 대표 PC: 디스크 암호화·잠금 [대표]

## 8. 재해·재난 대비
- 일일 백업(Supabase Pro, 7일 보관) ✅ · PITR 여부 확인 ⏳[대표] · 복구 절차: 대시보드 › Database › Backups › Restore

## 9. 개인정보 유출 사고 대응
- 감지: 관리자 변경 경보 ✅, 권한 점검 ✅, (예정) 가입·관리자 행위 급증 경보 ⏳
