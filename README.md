# 뜨개동네 (knit-neighbors)

동네 뜨개 친구를 지도에서 찾고, 프로필을 보고 친구가 되고, 채팅으로 약속을 잡는 위치기반 뜨개 커뮤니티.

- 앱: `docs/index.html` (단일 파일 PWA 프로토타입, GitHub Pages로 배포)
- 백엔드: Supabase 프로젝트 `thfcrodfaitzrzlrxyir` — 스키마는 `supabase_schema.sql`
- 로그인: Google OAuth (Supabase Auth) · 지도: Google Maps JavaScript API
- 뜨개 단계: knitup 기법사전 v1.3(60종) 기반 자가진단

배포 주소: https://yesbeyesnono.github.io/knit-neighbors/
